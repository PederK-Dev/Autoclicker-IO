# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| `1.0.x` | Yes |
| `< 1.0` | No |

Security fixes are made against the latest release line. If you are running a
different version, upgrade before reporting whether an issue is still present.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository:

1. Open the repository's **Security** tab.
2. Select **Advisories**, then **Report a vulnerability**.
3. Include the affected version, Windows/Python version, reproduction steps,
   impact, and any proof of concept needed to reproduce the issue safely.

Do not disclose an unpatched vulnerability in a public issue, pull request, or
discussion. If private vulnerability reporting is unavailable, contact the
maintainer through the repository profile and ask for a private reporting
channel; do not include exploit details in the first public message.

The maintainer will acknowledge reports as soon as practical, investigate the
impact, and coordinate a fix and disclosure timeline with the reporter. Please
avoid sending passwords, access tokens, personal data, or real-world targets in
reports.
